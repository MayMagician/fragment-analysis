# Fragment Case Study

Analysis of the Fragment marketplace of Telegram usernames, by using blockchain analysis, natural language processing and social network analysis techniques.

This repository contains the code and analysis used to investigate the linguistic and structural aspect of username communities in the Fragment marketplace, using a cross-dimensional analysis framework to understand the market behind.

The original dataset WNFTM is provided in a reduced form of 100 Telegram usernames (`fragment_dataset_100.csv`). For access to the complete dataset, contact: framay909@gmail.com.
